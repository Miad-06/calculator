# Calculator

A simple web calculator. Open `index.html` in a browser — no build step or dependencies.

- Add, subtract, multiply, divide, percent, change sign, backspace
- Keyboard support: digits, `+ - * /`, `Enter`/`=`, `Backspace`, `Esc` to clear
- Pressing `=` again repeats the last operation
- Follows your system's light or dark mode

Run tests (Node 18+):

```
node --test
```
